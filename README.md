# 封面工坊

> 篝火出品 · 收录于篝火 App 应用区

一行一个标题，按公众号头图和视频封面的尺寸批量出图，一眼看清每个标题在每个尺寸下的样子

![界面截图](docs/screenshot.png)

## 下载

到 [Releases](https://github.com/campfire-code/cover-studio/releases/latest) 下载对应安装包：

| 电脑 | 文件 |
|---|---|
| Windows 10 / 11 | `cover-studio_版本号_windows-x64-setup.exe` |
| Mac（Apple 芯片） | `cover-studio_版本号_mac-arm64.dmg` |
| Mac（Intel 芯片） | `cover-studio_版本号_mac-x64.dmg` |

第一次打开：
- **Windows**：如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
- **Mac**：如果提示「无法验证开发者」，打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」。

## 怎么用

1. **填标题**：在上方「标题列表」里一行写一个标题；行里的第一个「|」后面是副标题（可不写）；标题里写 `\n`（反斜杠加 n）可手动换行。也可以点「从 txt 导入」，或把 .txt 文件直接拖进窗口。一次最多处理 50 个标题，超出的会提示只处理前 50 个。
2. **选模板**：醒目黄黑、霓虹夜色、杂志衬线、撞色分栏、大图蒙层、极简黑白、便签手账，共 7 套，点一下下面的封面矩阵立即换样。
3. **选尺寸（可多选）**：公众号头图 2.35:1（1880×800）、公众号方图 1:1（1080×1080）、横版视频 16:9（1920×1080）、竖版视频 3:4（1080×1440）、竖屏视频 9:16（1080×1920）。至少选一个。
4. **换背景（可选）**：点「选择图片」（支持 JPG、PNG、WebP、BMP、GIF），或把图片拖进窗口；图片铺满并居中裁剪，模板会自动加色块或蒙层保证文字看得清。
5. **角标和署名**：角标是封面角上的一小块文字（如「第 12 期」），署名写在封面底部（如 `@你的账号名`），都可以留空。
6. **看矩阵**：下方「封面矩阵」每一行是一个标题、每一列是一个尺寸，同一列的封面按同一高度对齐。点任意一张可放大，键盘左右键翻页，Esc 关闭。
7. **导出**：点「导出 N 张 PNG」，在保存位置（默认「下载 / 封面工坊」，可点「选择保存位置」更改）下新建「封面-日期时间」文件夹，按「标题 × 尺寸」逐张存成 PNG，文件名形如 `01-标题-公众号头图.png`。
8. 标题、尺寸、模板、角标、署名、背景图路径和保存位置会自动记住，下次打开接着用。全程在本机完成，不联网。

## 验收用例

| 操作 | 应得到 |
|---|---|
| 首次打开（默认就是 `samples/示例-标题列表.txt` 的 4 个标题，角标「示例」） | 顶部显示「4 个标题 × 5 个尺寸 = 20 张」，矩阵 4 行 5 列，每个封面都能读到完整标题 |
| 点「从 txt 导入」选 `samples/示例-标题列表.txt` | 提示「已从 示例-标题列表.txt 读入 4 个标题」 |
| 取消勾选「公众号方图」「竖屏视频」 | 矩阵变成 4 行 3 列，顶部显示「4 个标题 × 3 个尺寸 = 12 张」 |
| 取消所有尺寸 | 矩阵位置显示「至少选一个尺寸」，导出按钮不可点 |
| 依次点 7 个模板 | 矩阵里全部封面立即换成对应风格，文字不超出封面 |
| 点「选择图片」选 `samples/示例背景-暖色渐变.png` | 全部封面铺上这张背景，文字仍然清楚；点垃圾桶图标可去掉 |
| 导入 `samples/示例-55个标题.txt` | 标题处只处理前 50 个，并提示「共 55 行，只处理前 50 个」 |
| 点任意一张封面，再按键盘右键 | 弹出放大预览，右键切到下一张，Esc 关闭 |
| 点「导出 N 张 PNG」 | 保存位置下出现「封面-日期时间」文件夹，PNG 张数等于「标题数 × 尺寸数」，尺寸与所选一致（如公众号头图 1880×800），提示「已导出 N 张 PNG」并可点「打开文件夹」 |

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
